# JavaScript Practice

My JavaScript learning repo: small practice programs, mini projects, and a few React experiments.

## Projects

| Project | What it is | Tech |
|---|---|---|
| [FocusBoard](FocusBoard/) | Task manager with priorities, filters, dark mode and localStorage | HTML, CSS, JS |
| MemoryCard | Memory card matching game | HTML, CSS, JS |
| ReactionTime | Reaction time tester | HTML, CSS, JS |
| whackMole | Whack-a-mole game | HTML, JS |
| [jsonplaceholder-posts](jsonplaceholder-posts/) | Fetches and shows posts from the JSONPlaceholder API | HTML, JS |
| [rsbuild-project](rsbuild-project/) | React app set up with Rsbuild | React |
| [cricket-game-react](cricket-game-react/), [reactjs](reactjs/) | React practice | React |

## Practice Topics

- **Basics:** functions, arrow functions, array methods (`reduce`, `shift`/`unshift`), objects
- **Concepts:** closures, prototypes, classes, memoization
- **Async:** promises, promise combinators, async/await, setTimeout
- **Small tasks:** FizzBuzz, even numbers, vowel count, guess the number, rock paper scissors, and more (`Task*.js` files)

## How to Run

- **`.js` files:** `node fileName.js`
